# wild-flow.com ブラッシュアップ計画 — 現状分析と施策案

作成日: 2026-07-27 ／ フェーズKPI: **認知度の獲得**（売上・問い合わせは次フェーズ）
戦略軸: Lemon8 / TikTok / YouTubeショートのショート動画で認知 → サイト流入。動画は単体で学びが完結する内容。ワンソース・マルチユース運用。

## 1. サイトの現状分析

### 1-1. 技術構成とページ構成

| 項目 | 現状 |
|---|---|
| スタック | React 19 + Vite + Tailwind v4 の SPA（クライアントサイドレンダリング） |
| ホスティング | Cloudflare Workers 静的アセット配信（`deploy.sh` = `wrangler deploy`） |
| CMS/DB | Supabase（posts / lessons / packages / settings / recovery_partners）＋ 自作管理画面（AdminPage、Tiptapエディタ内蔵） |
| ページ | ホーム／ブログ一覧・詳細／10問診断／60問診断／レッスン（一覧・詳細・体験・パッケージ）／リカバリー／プロフィール／FAQ・お問い合わせ・特商法・プライバシー／Animal Flow紹介（静的HTML） |

コンテンツ量: ページ骨格は十分に揃っている。トップは「身体のMBTI＝22動物タイプ診断」を軸にした診断LPとして完成度が高く、診断→レッスンへの導線も設計済み。ブログはSupabase駆動でCMSも動く。**サイトの「箱」はできていて、足りないのは流入とコンテンツ（特に動画）**という状態。

### 1-2. 認知獲得の観点での監査

**🔴 重大: SPAのため全URLが同一メタ情報**
- メタタグ・OGP・JSON-LDは [index.html](../index.html) に静的に1セットあるだけ。ブログ記事・診断ページ・レッスンページをSNSでシェアしても、**全部トップページと同じOGP画像・同じタイトル**で表示される。
- 検索エンジンから見ても全ページ実質同じ`<title>`。CSRなので本文のインデックスも不利。
- 診断結果のシェアボタン（X/LINE/コピー）は実装済みだが、シェアされるのは `/quiz/quick` の汎用OGP。**「私は○○型だった！」という結果カード画像が出ないため、バイラルの起爆力が半減している**。

**🟡 SEO基礎**
- [sitemap.xml](../public/sitemap.xml) は5 URLのみ。`/lessons` `/quiz/quick` `/blog/:id`（記事個別URL）が未掲載。記事が増えても sitemap に反映されない（自動生成なし）。
- JSON-LD は WebSite のみ。診断コンテンツ（Quiz）・記事（Article）・レッスン（Service/Event)の構造化データなし。
- robots.txt は適切（/admin除外）。canonical はトップのみ。

**🟡 SNS流入者が最初に見るページとして**
- トップのヒーロー「あなたの身体、何型の動物ですか？」→10問診断CTAは、診断系動画からの受け皿としては優秀。
- ただし**「動画で見たあの動きをもっと見たい」人の受け皿がない**。動画一覧ページが存在せず、Animal Flow紹介ページ（animalflow.html）は動画枠が6つ用意されているが全部「動画準備中」のまま。
- プロフィールページに X / Lemon8 リンクはあるが、TikTok / YouTube 欄がない（settings のフィールド自体にない）。

**🟢 モバイル表示**
- レスポンシブ対応済み。タップターゲット44px確保、ハンバーガーメニューあり。大きな問題なし。

**🟢 表示速度**
- ビルド実測: 初期ロードは index 128KB gzip + ページチャンク数KB。ページ単位のコード分割済み、巨大なAdminPage(153KB gzip)もlazyで分離済み。dist全体1.3MB。**現状は軽い**。
- 改善余地: Google Fonts 3ファミリー読込（Sora / DM Mono はほぼ装飾用）、記事本文表示前に Supabase フェッチが挟まる（スケルトンで緩和済み）。
- 計測: GA4等は未導入。Cloudflare RUM のみ（リファラー取得可）。**「SNS→サイト流入」というこのフェーズの中心KPIを計測する仕組みが未整備**（UTM運用も未定義）。

### 1-3. 動画の受け皿として見たときの課題

| 課題 | 詳細 |
|---|---|
| 縦型動画に未対応 | ブログ詳細のYouTube埋め込みは `aspect-video`（16:9）固定。ショート動画（9:16）を貼ると左右帯の間延び表示になる |
| iframe直埋め | facade（サムネクリックで初めてiframe読込）でないため、動画を並べるページを作ると一気に重くなる。lite-youtube-embed方式ならプレースホルダ表示で[約200倍高速](https://zenn.dev/sugamaan/articles/d8e8ba331e77db)になる |
| 動画一覧ページがない | 動画が資産として貯まる場所がなく、記事に1本ずつ紐づけるしかない |
| TikTok/Lemon8埋め込み | TikTok公式埋め込みはスクリプトが重く、Lemon8は埋め込み手段がほぼない。→ **サイト埋め込みはYouTube Shortsをマスターにするのが正解**（後述の運用フローで解決） |
| Postスキーマ | posts に `youtube_url` はあるが「縦型かどうか」「プラットフォーム別リンク」を持てない |

## 2. 参考リサーチ

### 2-1. 「ショート動画 → サイト/ブランド」がうまい事例

1. **Squat University（Dr. Aaron Horschig）** — TikTok 170万フォロワー。①「膝が痛い人はこれ」と**悩み1点突破の教育ショート**、②毎回同じ赤いバックドロップ+ホワイトボードで「見た瞬間に彼だと分かる」画面設計、③プロフィール→書籍・リハビリプログラムのサイトへ一点導線。**1動画1学びの完結性**がwildflowの方針と同型。
2. **Knees Over Toes Guy（Ben Patrick / ATG）** — 「常識の逆張り（膝はつま先より前に出していい）」という**フックが議論を呼ぶ構造**＋ビフォーアフターの実演。動画単体で驚きが完結し、詳細を知りたい人だけがサイト（オンラインコーチング）へ。
3. **Animal Flow 公式（Mike Fitch）** — まさに同ジャンルの本家。ムーブ名を冠した技解説ショート（Beast, Crab, Scorpion…）を**辞書型シリーズ**として蓄積 → ワークショップ・資格講座へ。技名がそのまま検索キーワードになる構造。
4. **16Personalities（MBTI診断）** — 動画ではないが「診断→シェア」バイラルの教科書。**結果ページがシェアされる前提のデザイン**（タイプ名+キャラ画像+特徴）で、シェアされた投稿自体が次の診断者を呼ぶ。wildflowの22動物タイプはこの構造をそのまま使える。
5. **竹脇まりな／のがちゃんねる（日本のフィットネス系）** — 「〜するだけ」「1日3分」の**ハードル最小化フック**＋毎回同じ構成の安心感で習慣視聴させ、書籍・アプリへ。日本語圏では「ガチ勢向け」より「運動苦手でもできる」訴求が伸びる。

**機能している要素の分解:**
- ① 1動画1学び（完結性）— 誘導ありきの「続きはサイトで」は伸びない
- ② 型の反復 — シリーズ名・定型構成・同じ画角/背景で「あの人だ」と認知される
- ③ フックは最初の1〜2秒 — 疑問形・逆張り・ビフォーアフターのいずれか
- ④ 結果/変化の可視化 — 動きの前後比較、できない→できる
- ⑤ プロフィールは一点導線 — リンクを絞り「診断はプロフィールから」で統一

### 2-2. プラットフォーム特性まとめ

共通仕様: **9:16・1080×1920で1本作れば3PFに使い回せる**（[媒体別サイズ早見表](https://0120.co.jp/blog/video-67/)）。伸びやすい尺は[15〜30秒](https://0120.co.jp/blog/video-105/)。

| | Lemon8 | TikTok | YouTubeショート |
|---|---|---|---|
| 性格 | 実用情報の「ライフスタイルメディア」。写真+テキストのブログ型投稿も強い（[解説](https://e-pace.co.jp/column/lemon8/)） | 発見型。新規アカウントでも爆発しうる。開始期に最適 | 検索・関連動画で**アーカイブが資産化**。長期の指名検索に効く |
| 尺 | 動画は短尺中心。カルーセル画像投稿が主力 | 〜10分可、推奨15〜30秒 | 最大3分、推奨15〜30秒 |
| 伸びる型 | ハウツーまとめ・統一感のあるトーン・保存されるTips | フック勝負・トレンド音源・コメント誘発 | 検索性のあるタイトル・シリーズ蓄積 |
| サイト導線 | **投稿本文にテキストリンク可**（3PF中最強）＋プロフィールリンク | プロフィールリンクは**ビジネスアカウント切替で即設置可**（個人アカは1,000フォロワー必要、[条件](https://www.theckb.com/archive/how-to-add-a-tiktok-link/)） | 説明欄・コメントのURLは**クリック不可**。[チャンネルページに最大14リンク](https://support.google.com/youtube/answer/13748639?hl=ja)＋動画内の口頭/テロップ誘導 |
| wildflowでの役割 | 診断結果まとめ・Tips記事で「保存」を取る＋本文リンクで直接流入 | 認知の主戦場。診断フック動画で新規リーチ | 同じ動画の資産化置き場 兼 **サイト埋め込みのマスター** |

### SNS → サイトの導線設計（具体）

- プロフィール文言（3PF共通の型）: 「あなたの身体は何型の動物？🐾 22タイプの野生診断はこちら↓」＋UTM付きリンク。

- YouTubeショートは説明欄リンクが踏めないため、**動画末尾テロップ「wild-flow.com で診断」**を全動画共通の締めに入れる（後述の「締め」定型）。

## 4. 動画コンテンツ企画

### 4-1. シリーズの「型」5本（再現可能フォーマット)

| 型 | シリーズ名(案) | 定型構成 | 狙い |
|---|---|---|---|
| A | **#あなたは何型診断** | 疑問形フック「○○できる？」→ その場でできる身体テスト1つ →「できた人は△△型の素質」→「10問診断はプロフィールから」 | 診断への最短導線。視聴者参加型でコメント誘発 |
| B | **#今日のアニマルムーブ** | 動物名ドン→ ムーブ実演（正面/横の2画角）→ よくある間違い1つ → 効く部位テロップ | Animal Flow辞書型の資産。検索性が高く本家公式と同じ勝ち筋 |
| C | **#野生のフィジカル雑学** | 動物の驚き数値フック（「チーターの加速はF1級」）→ 人間との比較 → 人間がその能力を鍛える動き1つ | 動画単体の学び完結性が最も高い。バズ枠 |
| D | **#30日野生チャレンジ** | Day n テロップ→ 今日の1ムーブ → 変化の記録（可動域などの定点比較） | 継続視聴・フォロー動機。ビフォーアフターの説得力 |
| E | **#しょっちゃんの野生日記** | 上海でのAnimal Flowとの出会い・24万円即決の話などを1話1分の語り | 人格・世界観でファン化。頻度低めでOK |

運用配分の目安: A:B:C = 2:2:1 を週ローテ、DとEは差し込み。**全動画共通の締め**: 「🐾 あなたの野生タイプは？」＋ wild-flow.com テロップ（1.5秒）。

### 4-2. 最初に撮る3本（各30〜60秒）

**① 型A「しゃがめますか？」**
- フック(0-3秒): 「かかとを付けたまま、深くしゃがめますか？」（画面いっぱいでフルスクワット実演）
- 中身(3-40秒): できない人が多い理由を1つだけ（足首の可動域）→ その場でできる判定基準「できた=柔軟性◎、かかとが浮く=○○型かも」→ 動物タイプに例える（「しゃがめるのは類人猿の基本姿勢。ゴリラは毎日これ」）
- 締め(40-50秒): 「あなたの身体が何型の動物か、10問で分かる無料診断やってます」＋サイトテロップ
- シーン: 自宅 or 公園の芝生。三脚固定・正面1画角+横1画角。
- キャプション案: 「かかと付けてしゃがめない人、実は◯◯が硬い🐾 10問1分の野生タイプ診断はプロフィールから #身体のMBTI #柔軟性テスト #野生診断」

**② 型B「Beast（ビースト）— 全部の基本になる四足歩行」**
- フック(0-2秒): 四つ這いから膝を2cm浮かせた静止姿勢をドンと見せ「この姿勢、10秒キツい人は体幹が…」
- 中身(2-40秒): Beastのセットアップを3ポイント（手の位置/膝2cm/背中フラット）→ よくある間違い(腰が高い)を✗→✓で見せる
- 締め: 「Animal Flowの他の動きもサイトにまとめてます」→ 共通締めテロップ
- シーン: 室内マット。真横からの固定画角メイン。
- キャプション案: 「道具ゼロ、床さえあればできる全身運動🦍 Beastは全ムーブの基本。#アニマルフロー #体幹トレーニング #自重トレ」

**③ 型C「チーターは時速100km。でも90秒しか走れない」**
- フック(0-3秒): 「チーターって実は超スタミナない動物です」（意外性の逆張り）
- 中身(3-40秒): スピード特化と引き換えの持久力のなさ → 人間にも同じことが起きてる（速いけどすぐバテる人）→ 「筋力・持久力・スピード・柔軟性・調整力、全部高い動物はいない。人間も同じで、どれかが伸びしろ」
- 締め(40-55秒): 「あなたの伸びしろがどこか、22種の動物で診断できます」＋共通締め
- シーン: 語りメイン（顔出し or 手元+テロップ）。動物映像はフリー素材 or イラスト静止画で可。
- キャプション案: 「チーターは90秒でバテる🐆 あなたの身体の"伸びしろ"はどの能力？ #野生のフィジカル雑学 #身体のMBTI」

### 4-3. ワンソース・マルチユース運用フロー

```
【撮影】9:16・1080×1920で撮る（スマホ縦+三脚、1本の撮影で素材2画角）
   ↓
【編集】CapCut等で1本仕上げ（テロップ・締めテロップ共通素材を使い回し）
   ├─ TikTok版: トレンド音源に差し替え可、フック強め
   ├─ YouTubeショート版: 検索されるタイトル(「Animal Flow Beast やり方」等)
   └─ Lemon8版: 動画+カバー画像+本文に手順テキスト再掲＋本文にサイトリンク
   ↓
【投稿】3PFへ投稿（フック/キャプションだけPF最適化、動画本体は共通）
   ↓
【サイト埋め込み】= YouTubeショートをマスターにする
   ├─ /videos ギャラリーに自動掲載（youtube_url を登録するだけ）
   │    ※ 9:16のfacade表示。クリック時のみYouTube iframe読込なので何本並べても軽い
   └─ 関連ブログ記事に埋め込み（例: Beast解説記事にBeast動画）
        → 動画のテキスト版記事にすればSEO資産にもなる（動画→記事の二次利用）
```

- サイト埋め込みにTikTok/Lemon8を使わない理由: TikTok埋め込みはスクリプトが重くページ速度を殺す。Lemon8は埋め込み手段が事実上ない。YouTube埋め込みは軽量化手法（facade）が確立しており、動画が消えない資産になる。
- 週次ルーティン(案): 週2本撮影(まとめ撮り) → 週2〜3本投稿 → 投稿後に `/videos` へ登録(1分作業) → 月1でRUM/GA4の流入レポート確認。
