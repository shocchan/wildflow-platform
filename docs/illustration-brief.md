## 進め方（memory: design-via-chatgpt に従う）
1. 1枚目（beast.png）で画風が合うかを2案出して比較。合ったらその会話を続けて残りを生成（画風がぶれない）
2. 検品基準：青タオル／グレーパーカーが維持されているか、体の要点が正しいか、文字が入っていないか、背景が透過か
3. 採用画像は `~/wildflow-platform/public/img/shocchan/<ファイル名>` に保存 → 1024 のまま WebP 化（品質80）→ `<img width height>` を付けて組み込み
4. 不採用画像は捨てる。同じ画像を別スロットに使い回さない（md5 で確認）
