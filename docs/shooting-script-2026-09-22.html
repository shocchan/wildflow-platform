Setup

準備（現地でこの順に）

📱 カメラ設定

  • スマホ横向き・1080p・30fps（60fpsでも可）
  • 露出とフォーカスをロック（画面長押し）
  • グリッド表示ON。床の線を水平に
  • 機内モード・通知OFF・容量5GB以上空ける

🎥 三脚の位置（基本＝真横）

  • レンズの高さ：床から60〜70cm（四つん這いの背中と同じ高さ）
  • 距離：被写体から約3m。全身＋前後の余白1mずつ
  • 「斜め前」は真横から手前に45°回す
  • 一度決めたら動かさない（つなぎで違和感が出る）

👕 服装・見た目

  • グレーのパーカー＋頭に青いタオル（イラストと同じ。ここが一番大事）
  • 下は青系のパンツ。靴は履いたまま（室内用）
  • ラケット1本とシャトル2個を画面の隅に置く（バドの文脈）

💡 場所・光

  • 体育館のコートの線が背景に入る位置。壁際より中央寄り
  • 窓を背にしない（逆光NG）。天井照明はそのままでOK
  • 床に反射する光が強ければ、位置を1〜2mずらす
  • 床に置くスマホ用に、もう1台あれば手元カットが撮れる
各カット「3・2・1」で始めて、終わったら2秒止まってから録画停止。編集で前後を切るための余白です。1テイクで決めようとしない。良いのを1本選べばいい。

Cut list

動画カット表（撮影順）

「尺」は録画する長さ。使用先は右端。結果＝10問診断の結果ページ「今日やる1動作」、入門＝/beginner と /animalflow の6ステップ、バド＝/badminton の練習前5分。

#動き尺カメラやること（画面に映す要点）NG（撮り直し）使用先
A1手首くるくる
Wrist Mobilizations		40秒斜め前 45°
やや手元寄り		四つん這いで手を床に。①前後に揺れる ②左右 ③手の甲をついて逆方向 ④空中でくるくる。各10秒。手のひらと手首が大きく映ること手が画面の端に切れる／体が入りすぎて手首が小さい入門①バド
A2スタティック・ビースト
Static Beast		45秒真横四つん這い → 膝を2〜3cm浮かせて10秒 → 膝を下ろして5秒休む、を3回。手は肩の真下、膝は腰の真下、目線は下。膝と床のすき間が見えること膝が床についたまま／腰が反る・丸まる／頭が上がる結果：筋力入門②バド
A3スタティック・クラブ
Static Crab		45秒真横仰向けで手と足をつき、お尻を2〜3cm浮かせて10秒×3回（間5秒）。指先は後ろ、胸を天井へ。お尻が浮いているのが見えることお尻が床についている／腰だけで反っている結果：持久力入門②
A4クラブ・リーチ
Crab Reach		40秒斜め前 45°クラブから片手を頭上後方へ伸ばし、胸を天井に開く。ゆっくり呼吸1回分止めて戻す。左右交互に3回ずつ。目線は手の先お尻が落ちる／腰で反って胸が開いていない／速すぎる結果：柔軟性入門③バド
A5伸ばす3種
Loaded Beast → Ape Reach → Scorpion Reach		60秒斜め前 45°各動きを3回ずつ、間を空けずに。Loaded Beast（お尻をかかとへ引く）→ Ape Reach（しゃがんで背中を丸め開く）→ Scorpion Reach（足を後ろに振る）。編集で3分割する3種の切り替えで立ち上がる／カメラ位置を変える入門③
A6動物歩き
Traveling Beast ＋ Traveling Crab		60秒真横
距離4mに広げる		ビーストで前へ4歩・後ろへ4歩を2往復 → クラブで同じく2往復。上下動を抑えてフラットに。画面の端から端まで使う画面から出る／膝が床につく／速すぎて形が崩れる入門④
A7アンダースウィッチ
Underswitch		40秒斜め前 45°ビースト → 片足を反対の手の下にくぐらせてクラブへ → 戻る。左右交互に5回、ゆっくり。腰がひねれて向きが変わる瞬間が見えること足が手の下を通っていない／勢いで回る結果：スピード入門⑤
A8サイドキックスルー
Side Kickthrough		30秒斜め前 45°ビーストから片足を横へ蹴り出し、反対の手を上げる。左右3回ずつ。A7と合わせて「⑤つなげる」の動画になる蹴った足が床についている／体がねじれすぎて倒れる入門⑤
A9ビースト・リーチ
Beast Reach		40秒真横 やや前ビーストから対角の手と足を同時に前へ伸ばし、3点で支えて2秒キープ → 戻す。左右5回。骨盤が傾かないこと伸ばした手足が床につく／骨盤が回る／膝が床につく結果：調整力入門⑥
A10フロー
Beast Flow（自由）		60秒真横
距離4m		ここまでの動きを止まらずにつなげて60秒。きれいでなくていい。「流れている」ことが伝わればOK。最後に1回ビーストで止まって終わる途中で立ち上がる／カメラを見る入門⑥トップ将来
「バド：練習前5分」の動画は撮り足し不要。 A1・A2・A4 をつないで60秒に編集して作ります。結果ページの5本も A2・A3・A4・A7・A9 をそのまま使うので、撮るのは上の10本だけです。
